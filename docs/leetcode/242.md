## 문제

[Valid Anagram - LeetCode](https://leetcode.com/problems/valid-anagram/description/)

문자열 `s` 와 `t`가 주어졌을 때, `t`가 `s`의 [애너그램](https://ko.wikipedia.org/wiki/%EC%96%B4%EA%B5%AC%EC%A0%84%EC%B2%A0)이면 `true`, 아니면 `false`를 반환하는 문제.

## 풀이 1

### 아이디어

`s`에서 각 문자가 몇번 등장하는지 세어준다. (`charCount`)
`t`에서 문자의 개수를 세어주면서 `charCount`의 값을 감소시킨다.
문자의 개수가 부족하거나 남는다면 애너그램이 아니다.

### 코드

```typescript
function isAnagram(s: string, t: string): boolean {
    const charCount: Record < string, number > = {};
    for (const char of s) {
        charCount[char] = (charCount[char] ?? 0) + 1;
    }

    for (const char of t) {
        if (charCount[char] === undefined || charCount[char] === 0) {
            return false;
        }
        charCount[char]--;
    }

    return Object.values(charCount).every((count) => count === 0);
}
```

### 시간 / 공간 복잡도

- 시간 복잡도: O(n + n + k) => O(n) (n: `s`와 `t`의 길이, k: 두 문자열에 등장하는 고유 문자 수)
- 공간 복잡도: 문자 등장 횟수를 세어주는 `charCount`에 필요한 공간이므로 O(n)
